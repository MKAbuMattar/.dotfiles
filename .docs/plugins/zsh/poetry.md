# poetry-plugin

## NAME

**poetry-plugin** — lazy zsh completion bootstrap for the Poetry
Python packaging tool.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "poetry" ...)
```

## DESCRIPTION

This plugin registers a cached zsh completion definition for `poetry`.
On load it ensures `$ZSH_CACHE_DIR/completions` exists, and — if the
cache file is missing — autoloads `_poetry` and binds it via
`_comps[poetry]` so completion is available immediately. The cached
script is regenerated asynchronously (`&|`) using
`poetry completions zsh` when missing or older than seven days.

## EFFECTS

- Returns immediately if `poetry` is not on PATH.
- Sets `ZSH_CACHE_DIR` to `${HOME}/.cache/zsh` when unset and ensures
  `$ZSH_CACHE_DIR/completions` exists.
- Autoloads `_poetry` and registers it in `_comps[poetry]` when the
  cache file does not yet exist.
- Writes (or regenerates after 7 days) `_poetry` asynchronously via
  `poetry completions zsh >| ... &|`.

## FUNCTIONS

This plugin defines no user-callable functions. It only installs the
`_poetry` completion script consumed by zsh's `compsys`.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to
  `${HOME}/.cache/zsh` when unset.

## FILES

- `$ZSH_CACHE_DIR/completions/_poetry` — generated by
  `poetry completions zsh`. Refreshed when missing or older than 7 days.
- `.plugins/.zsh/poetry/poetry.plugin.zsh` — the plugin source.

## REQUIREMENTS

- A working `poetry` binary on PATH.
- A zsh with `compsys` available.

## KEY BINDINGS

None.
