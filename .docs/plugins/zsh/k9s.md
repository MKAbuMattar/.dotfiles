# k9s-plugin

## NAME

**k9s-plugin** — lazy zsh completion bootstrap for the k9s Kubernetes
TUI.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "k9s" ...)
```

## DESCRIPTION

This plugin registers a cached zsh completion definition for `k9s`. On
load it ensures `$ZSH_CACHE_DIR/completions` exists, prepends it to
`fpath`, and — if the cache file is missing — autoloads `_k9s` and
binds it via `_comps[k9s]` so completion is wired up before `compinit`
runs again. The completion script itself is regenerated asynchronously
(`&|`) the first time it is needed, and again whenever it becomes
stale (older than seven days).

## EFFECTS

- Returns immediately if `k9s` is not on PATH.
- Creates `$ZSH_CACHE_DIR/completions` (default `$HOME/.cache/zsh/completions`).
- Prepends that directory to `fpath` once per shell.
- Autoloads `_k9s` and registers it in `_comps[k9s]` when the cache file
  does not yet exist.
- Writes (or regenerates after 7 days) `_k9s` asynchronously via
  `k9s completion zsh >| ... &|`.

## FUNCTIONS

This plugin defines no user-callable functions. It only installs the
`_k9s` completion script consumed by zsh's `compsys`.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to `$HOME/.cache/zsh`
  when unset.

## FILES

- `$ZSH_CACHE_DIR/completions/_k9s` — generated by
  `k9s completion zsh`. Refreshed when missing or older than 7 days.
- `.plugins/.zsh/k9s/k9s.plugin.zsh` — the plugin source.

## REQUIREMENTS

- A working `k9s` binary on PATH.
- A zsh with `compsys` available.

## KEY BINDINGS

None.
