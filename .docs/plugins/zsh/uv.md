# uv-plugin

## NAME

**uv-plugin** — lazy zsh completion bootstrap for the Astral `uv` /
`uvx` Python package manager.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "uv" ...)
```

## DESCRIPTION

This plugin registers cached zsh completion definitions for both `uv`
and `uvx`. On load it ensures `$ZSH_CACHE_DIR/completions` exists and
prepends it to `fpath`. If either cache file is missing, the plugin
autoloads `_uv` / `_uvx` and binds them via `_comps[uv]` /
`_comps[uvx]` so completion is available immediately.

The cached scripts are regenerated asynchronously (`&|`) when missing
or older than seven days:

- `_uv` via `uv generate-shell-completion zsh`.
- `_uvx` via `uvx --generate-shell-completion zsh`.

## EFFECTS

- Returns immediately if `uv` is not on PATH.
- Creates `$ZSH_CACHE_DIR/completions` (default `$HOME/.cache/zsh/completions`).
- Prepends that directory to `fpath` once per shell.
- Autoloads `_uv` / `_uvx` and registers them in `_comps[...]` when
  the corresponding cache file does not yet exist.
- Writes (or regenerates after 7 days) `_uv` and `_uvx` asynchronously.

## FUNCTIONS

This plugin defines no user-callable functions. It only installs the
`_uv` and `_uvx` completion scripts consumed by zsh's `compsys`.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to `$HOME/.cache/zsh`.

## FILES

- `$ZSH_CACHE_DIR/completions/_uv` — generated by
  `uv generate-shell-completion zsh`.
- `$ZSH_CACHE_DIR/completions/_uvx` — generated by
  `uvx --generate-shell-completion zsh`.
- `.plugins/.zsh/uv/uv.plugin.zsh` — the plugin source.

## REQUIREMENTS

- A working `uv` binary on PATH. `uvx` ships alongside `uv` and is
  assumed to be available for the second completion generator.
- A zsh with `compsys` available.

## KEY BINDINGS

None.
