# helm-plugin

## NAME

**helm-plugin** — lazy zsh completion bootstrap for the Helm package manager.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "helm" ...)
```

## DESCRIPTION

This plugin registers a cached zsh completion definition for `helm`. On
load it ensures `$ZSH_CACHE_DIR/completions` exists, prepends it to
`fpath`, and asks Helm itself to emit a `_helm` completion script the
first time it is needed. The cached script is reused on subsequent shell
startups until it becomes stale (older than seven days), at which point
the plugin regenerates it.

The plugin performs no other side effects: it does not export new
variables for daily use, does not bind keys, and does not define
user-visible functions.

## EFFECTS

- Returns immediately if `helm` is not on PATH.
- Creates `$ZSH_CACHE_DIR/completions` (default `$HOME/.cache/zsh/completions`).
- Prepends that directory to `fpath` once per shell.
- Writes (or regenerates after 7 days) `_helm` into the completion cache.

## FUNCTIONS

This plugin defines no user-callable functions. It only installs the
`_helm` completion script consumed by zsh's `compsys`.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to `$HOME/.cache/zsh`
  when unset.

## FILES

- `$ZSH_CACHE_DIR/completions/_helm` — generated by
  `helm completion zsh`. Refreshed when missing or older than 7 days.
- `.plugins/.zsh/helm/helm.plugin.zsh` — the plugin source.

## REQUIREMENTS

- A working `helm` binary on PATH.
- A zsh with `compsys` available (`compinit` must run after the plugin
  is sourced).

## KEY BINDINGS

None.
