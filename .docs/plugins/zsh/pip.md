# pip-plugin

## NAME

**pip-plugin** — lazy zsh completion bootstrap for `pip` / `pip3`,
plus a local package-index cache for richer custom completions.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "pip" ...)
```

## DESCRIPTION

This plugin registers a cached zsh completion definition for `pip`. On
load it ensures `$ZSH_CACHE_DIR/completions` exists, prepends it to
`fpath`, and also adds the plugin's local `completions/` directory (if
one ships with the dotfiles) so any hand-written completions are
discoverable.

The cached `_pip` file is regenerated by invoking `pip completion --zsh`
when missing or older than seven days, falling back to `pip3` if only
that binary is available.

The plugin additionally seeds two variables used by the bundled custom
completion to suggest package names from PyPI:

- `ZSH_PIP_CACHE_FILE` — where to keep a local list of package names.
- `ZSH_PIP_INDEXES` — a list of simple-index URLs to scrape (defaults
  to PyPI).

## EFFECTS

- Returns immediately if neither `pip` nor `pip3` is on PATH.
- Creates `$ZSH_CACHE_DIR/completions` (default `$HOME/.cache/zsh/completions`).
- Prepends that directory to `fpath` once per shell.
- Adds the plugin-local `completions/` directory to `fpath` when it
  exists.
- Writes (or regenerates after 7 days) `_pip` into the completion cache
  by running `pip completion --zsh` (preferring `pip`, falling back to
  `pip3`).
- Sets `ZSH_PIP_CACHE_FILE` and `ZSH_PIP_INDEXES`.

## FUNCTIONS

This plugin defines no user-callable functions of its own. It relies
on the generated `_pip` completion and any hand-written completion
shipped in the plugin's local `completions/` directory.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to `$HOME/.cache/zsh`.
- `XDG_CACHE_HOME` — preferred location for the package-name cache.
  Falls back to `~/.cache` and then `~/.pip` when unset.
- `ZSH_PIP_CACHE_FILE` — path to the package-name cache.
  Set to `${XDG_CACHE_HOME:-$HOME/.cache}/pip/zsh-cache` when that
  directory exists, otherwise `~/.pip/zsh-cache`.
- `ZSH_PIP_INDEXES` — array of simple-index URLs to scrape. Defaults
  to `(https://pypi.org/simple/)`.

## FILES

- `$ZSH_CACHE_DIR/completions/_pip` — generated by
  `pip completion --zsh`. Refreshed when missing or older than 7 days.
- `${XDG_CACHE_HOME:-$HOME/.cache}/pip/zsh-cache` or `~/.pip/zsh-cache`
  — local PyPI name cache for the completion (created on demand by the
  completion function itself).
- `.plugins/.zsh/pip/pip.plugin.zsh` — the plugin source.

## REQUIREMENTS

- Either `pip` or `pip3` on PATH.
- A zsh with `compsys` available.

## KEY BINDINGS

None.
