# kubectl-plugin

## NAME

**kubectl-plugin** — lazy zsh completion bootstrap for the Kubernetes
CLI.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "kubectl" ...)
```

## DESCRIPTION

This plugin registers a cached zsh completion definition for `kubectl`.
On load it ensures `$ZSH_CACHE_DIR/completions` exists, prepends it to
`fpath`, and — if the cache file is missing — autoloads `_kubectl` and
binds it via `_comps[kubectl]` so completion is available immediately
without waiting for the next `compinit`. The completion script itself
is regenerated asynchronously (`&|`) the first time it is needed, and
again whenever it becomes stale (older than seven days).

## EFFECTS

- Returns immediately if `kubectl` is not on PATH.
- Creates `$ZSH_CACHE_DIR/completions` (default `$HOME/.cache/zsh/completions`).
- Prepends that directory to `fpath` once per shell.
- Autoloads `_kubectl` and registers it in `_comps[kubectl]` when the
  cache file does not yet exist.
- Writes (or regenerates after 7 days) `_kubectl` asynchronously via
  `kubectl completion zsh >| ... &|`.

## FUNCTIONS

This plugin defines no user-callable functions. It only installs the
`_kubectl` completion script consumed by zsh's `compsys`.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to `$HOME/.cache/zsh`
  when unset.

## FILES

- `$ZSH_CACHE_DIR/completions/_kubectl` — generated by
  `kubectl completion zsh`. Refreshed when missing or older than 7 days.
- `.plugins/.zsh/kubectl/kubectl.plugin.zsh` — the plugin source.

## REQUIREMENTS

- A working `kubectl` binary on PATH.
- A zsh with `compsys` available.

## KEY BINDINGS

None.
