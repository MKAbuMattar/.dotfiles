# pnpm-plugin

## NAME

**pnpm-plugin** — lazy zsh completion bootstrap for the pnpm package
manager.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "pnpm" ...)
```

## DESCRIPTION

This plugin registers a cached zsh completion definition for `pnpm`.
On load it ensures `$ZSH_CACHE_DIR/completions` exists, and — if the
cache file is missing — autoloads `_pnpm` and binds it via
`_comps[pnpm]` so completion is available immediately. The cached
script is regenerated asynchronously (`&|`) using
`pnpm completion zsh` when missing or older than seven days.

The plugin assumes `PNPM_HOME` (and the corresponding `PATH` entry)
are configured by the user's shell init — typically by the pnpm
installer's own snippet in `~/.zshrc`. This plugin focuses solely on
completion wiring.

## EFFECTS

- Returns immediately if `pnpm` is not on PATH.
- Sets `ZSH_CACHE_DIR` to `${HOME}/.cache/zsh` when unset and ensures
  `$ZSH_CACHE_DIR/completions` exists.
- Autoloads `_pnpm` and registers it in `_comps[pnpm]` when the cache
  file does not yet exist.
- Writes (or regenerates after 7 days) `_pnpm` asynchronously via
  `pnpm completion zsh >| ... &|`.

## FUNCTIONS

This plugin defines no user-callable functions. It only installs the
`_pnpm` completion script consumed by zsh's `compsys`.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to
  `${HOME}/.cache/zsh` when unset.
- `PNPM_HOME` — not exported by this plugin; expected to be set
  elsewhere in the shell init so that pnpm-installed binaries are on
  `PATH`.

## FILES

- `$ZSH_CACHE_DIR/completions/_pnpm` — generated by
  `pnpm completion zsh`. Refreshed when missing or older than 7 days.
- `.plugins/.zsh/pnpm/pnpm.plugin.zsh` — the plugin source.

## REQUIREMENTS

- A working `pnpm` binary on PATH.
- A zsh with `compsys` available.

## KEY BINDINGS

None.
