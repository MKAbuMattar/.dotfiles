# rust-plugin

## NAME

**rust-plugin** — lazy zsh completion bootstrap for `rustup` and
`cargo`, including a sysroot-aware `_cargo` shim.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "rust" ...)
```

## DESCRIPTION

This plugin wires up completion for the Rust toolchain. On load it
ensures `$ZSH_CACHE_DIR/completions` exists, prepends it to `fpath`,
and also adds the plugin's local `completions/` directory if present.

If the cache files are missing, the plugin autoloads `_cargo` and
`_rustup`, registering them via `_comps[cargo]` / `_comps[rustup]` so
completion is available immediately.

Then it regenerates the cached scripts asynchronously when missing or
older than seven days:

- `_rustup` is produced by `rustup completions zsh`.
- `_cargo` is **not** produced by `cargo` directly. Instead the plugin
  writes a small shim that, at completion time, sources
  `<sysroot>/share/zsh/site-functions/_cargo` from the currently
  active toolchain (as reported by `rustup default`). This means
  switching toolchains automatically uses the matching `_cargo`.

## EFFECTS

- Returns immediately if either `rustup` or `cargo` is missing.
- Creates `$ZSH_CACHE_DIR/completions` (default `$HOME/.cache/zsh/completions`).
- Prepends that directory to `fpath` once per shell.
- Adds the plugin-local `completions/` directory to `fpath` when it
  exists.
- Autoloads `_cargo` and `_rustup`, registering each in `_comps[...]`
  when the corresponding cache file does not yet exist.
- Writes (or regenerates after 7 days) `_rustup` asynchronously via
  `rustup completions zsh >| ... &|`.
- Writes a `_cargo` shim (only when the cache file is missing or
  stale) that delegates to the toolchain's bundled `_cargo`.

## FUNCTIONS

This plugin defines no user-callable functions. It only installs
completion scripts consumed by zsh's `compsys`.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to `$HOME/.cache/zsh`.

## FILES

- `$ZSH_CACHE_DIR/completions/_rustup` — generated by
  `rustup completions zsh`.
- `$ZSH_CACHE_DIR/completions/_cargo` — hand-written shim that sources
  the toolchain's own `_cargo` via `rustup run ... rustc --print sysroot`.
- `<sysroot>/share/zsh/site-functions/_cargo` — the upstream Cargo
  completion sourced lazily by the shim.
- `.plugins/.zsh/rust/rust.plugin.zsh` — the plugin source.

## REQUIREMENTS

- Both `rustup` and `cargo` on PATH (the plugin no-ops unless both are
  available).
- A working default toolchain (`rustup default`) so the shim can
  resolve a sysroot.
- A zsh with `compsys` available.

None.
