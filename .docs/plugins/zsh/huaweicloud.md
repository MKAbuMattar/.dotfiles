# huaweicloud-plugin

## NAME

**huaweicloud-plugin** — lazy zsh completion bootstrap for the Huawei
Cloud CLI (`hcloud`).

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "huaweicloud" ...)
```

## DESCRIPTION

This plugin registers a cached zsh completion definition for the
`hcloud` command-line tool used to interact with Huawei Cloud services.
On load it ensures `$ZSH_CACHE_DIR/completions` exists, prepends it to
`fpath`, and asks `hcloud` itself to emit a `_hcloud` completion script
the first time it is needed. The cached script is reused on subsequent
shell startups until it becomes stale (older than seven days), at which
point the plugin regenerates it.

The plugin performs no other side effects: it does not export new
variables for daily use, does not bind keys, and does not define
user-visible functions.

## EFFECTS

- Returns immediately if `hcloud` is not on PATH.
- Creates `$ZSH_CACHE_DIR/completions` (default `$HOME/.cache/zsh/completions`).
- Prepends that directory to `fpath` once per shell.
- Writes (or regenerates after 7 days) `_hcloud` into the completion cache.

## FUNCTIONS

This plugin defines no user-callable functions. It only installs the
`_hcloud` completion script consumed by zsh's `compsys`.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to `$HOME/.cache/zsh`
  when unset.

## FILES

- `$ZSH_CACHE_DIR/completions/_hcloud` — generated by
  `hcloud completion zsh`. Refreshed when missing or older than 7 days.
- `.plugins/.zsh/huaweicloud/huaweicloud.plugin.zsh` — the plugin source.

## REQUIREMENTS

- A working `hcloud` binary on PATH.
- A zsh with `compsys` available.

## KEY BINDINGS

None.
