# pipenv-plugin

## NAME

**pipenv-plugin** — lazy zsh completion bootstrap for Pipenv with
optional automatic virtualenv activation per `Pipfile`.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "pipenv" ...)
```

## DESCRIPTION

The plugin registers a cached zsh completion definition for `pipenv`.
On load it ensures `$ZSH_CACHE_DIR/completions` exists, prepends it to
`fpath`, and — if the cache file is missing — autoloads `_pipenv` and
binds it via `_comps[pipenv]` so completion is available immediately.
The cached script is rebuilt asynchronously (`&|`) using the
`_PIPENV_COMPLETE=zsh_source pipenv` invocation when missing or older
than seven days.

When the user has _not_ explicitly disabled it (via
`zstyle ':omz:plugins:pipenv' auto-shell false`), the plugin also
installs a `chpwd` hook named `_togglePipenvShell` that:

- Activates the project's Pipenv virtualenv automatically whenever
  the new working directory contains a `Pipfile` and no env is
  currently active.
- Deactivates the active virtualenv when leaving its containing
  directory tree (it does **not** deactivate when descending into
  subdirectories).

State is tracked via `PIPENV_ACTIVE` (set to `1` while active) and
`pipfile_dir` (the directory of the activating `Pipfile`).

## EFFECTS

- Returns immediately if `pipenv` is not on PATH.
- Creates `$ZSH_CACHE_DIR/completions` (default `$HOME/.cache/zsh/completions`).
- Prepends that directory to `fpath` once per shell.
- Autoloads `_pipenv` and registers it in `_comps[pipenv]` when the
  cache file does not yet exist.
- Writes (or regenerates after 7 days) `_pipenv` asynchronously via
  `_PIPENV_COMPLETE=zsh_source pipenv >| ... &|`.
- When `auto-shell` is enabled (the default), defines
  `_togglePipenvShell` and registers it with `add-zsh-hook chpwd` and
  invokes it once for the current directory.

## FUNCTIONS

- `_togglePipenvShell` — invoked on every `chpwd`; sources the venv
  activate script for the discovered `Pipfile` and exports
  `PIPENV_ACTIVE=1`, or calls `deactivate` when leaving the project.
  Only installed when the `auto-shell` zstyle is true.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to `$HOME/.cache/zsh`.
- `PIPENV_ACTIVE` — set to `1` while a Pipenv venv is active; cleared
  when leaving. Read by the toggle function to avoid double-activating.
- `pipfile_dir` — exported by the toggle function and used to detect
  when the user has left the project tree.

## ZSTYLES

- `:omz:plugins:pipenv auto-shell` — set to a falsey value
  (`zstyle ':omz:plugins:pipenv' auto-shell false`) to disable the
  automatic activation hook. Enabled by default via `zstyle -T`.

## FILES

- `$ZSH_CACHE_DIR/completions/_pipenv` — generated by
  `_PIPENV_COMPLETE=zsh_source pipenv`. Refreshed when missing or
  older than 7 days.
- `./Pipfile` — presence triggers automatic venv activation.
- `.plugins/.zsh/pipenv/pipenv.plugin.zsh` — the plugin source.

## REQUIREMENTS

- A working `pipenv` binary on PATH.
- A zsh with `compsys` and `add-zsh-hook` available.

## KEY BINDINGS

None.
