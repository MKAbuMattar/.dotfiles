# gradle-plugin

## NAME

**gradle-plugin** — lazy zsh completion bootstrap for the Gradle build tool.

## SYNOPSIS

```text
# Enable by adding to the PLUGINS array in ~/.zshrc:
PLUGINS=(... "gradle" ...)
```

## DESCRIPTION

This plugin registers a cached zsh completion definition for `gradle`. On
load it ensures `$ZSH_CACHE_DIR/completions` exists, prepends it to
`fpath`, and asks Gradle itself to emit a `_gradle` completion script the
first time it is needed. The cached script is reused on subsequent shell
startups until it becomes stale (older than seven days), at which point
the plugin regenerates it.

The plugin performs no other side effects: it does not export new
variables for daily use, does not bind keys, and does not define
user-visible functions.

## EFFECTS

- Returns immediately if `gradle` is not on PATH.
- Creates `$ZSH_CACHE_DIR/completions` (default `$HOME/.cache/zsh/completions`).
- Prepends that directory to `fpath` once per shell.
- Writes (or regenerates after 7 days) `_gradle` into the completion cache.

## FUNCTIONS

This plugin defines no user-callable functions. It only installs the
`_gradle` completion script consumed by zsh's `compsys`.

## ENVIRONMENT

- `ZSH_CACHE_DIR` — base cache directory. Defaults to `$HOME/.cache/zsh`
  when unset. The plugin reads this variable to decide where to drop
  generated completion files.

## FILES

- `$ZSH_CACHE_DIR/completions/_gradle` — generated by
  `gradle --completion=zsh`. Refreshed when missing or older than 7 days.
- `.plugins/.zsh/gradle/gradle.plugin.zsh` — the plugin source.

## REQUIREMENTS

- A working `gradle` binary on PATH (it is invoked once to emit
  completions).
- A zsh new enough to support the standard `compsys` framework
  (`compinit` must run after the plugin is sourced).

## KEY BINDINGS

None.
